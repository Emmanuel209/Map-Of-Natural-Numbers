# Map-Of-Natural-Numbers
Project Emergence 
The project stemmed from the desire to explore OpenGL programming using Python, a language we had already learned. While the course focused on OpenGL implementation with C++, we decided to challenge ourselves by applying our knowledge to a different language, expanding our skillset and fostering independent learning.

Technology implemented Python and OpenGL

To clone a Git repository, you must follow the following steps: 
1. On GitHub.com, navigate to the repository home page.
![Steps](<Pictures/Step 1.png>)

2. Above the file list, click Code. 
![Steps](<Pictures/Step 2.png>)

3. Copy the repository URL.
4. Open the terminal on your local machine (GitBash). 
5. Type git clone and paste the URL you copied earlier. 
6. Press Enter to create the local clone.
![Steps](<Pictures/Final step.png>)

And voila, the repository was cloned correctly.
